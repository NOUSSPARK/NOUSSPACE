# Linear

Project management / issue tracking, connected via MCP.

- Workspace: **NOUSSPACE** (https://linear.app/nousspace)
- Team: `NOUSSPACE` (key `NOU`)
- Auth: OAuth via OpenCode MCP (`opencode.jsonc` in repo root, server key `linear`).

## Usage

I can list/create/update issues, projects, comments, cycles, milestones, labels, etc. Ask me to file a ticket, e.g. "Create an issue for adding a Contact page."
