# Three.js

**URL:** https://threejs.org/
**Type:** Tool / Library — 3D graphics for the web (WebGL/WebGPU)

## What it is

Three.js is the standard JavaScript 3D library. It provides scenes, cameras, geometries, materials, lights, and renderers (WebGL/WebGPU) plus helpers (controls, loaders, post-processing).

## Why it matters for Nous Space

- Could power immersive hero backgrounds, 3D product/logo scenes, or interactive visual accents.
- Pairs well with the cinematic/moody direction (Odyssey reference) and animated brand feel (Vessa).
- React integration via `@react-three/fiber` + `@react-three/drei`.

## Things to explore

- React Three Fiber setup in Next.js App Router.
- Performance: code-splitting, dynamic import, reduced motion fallback.
- WebGPU renderer (experimental).
