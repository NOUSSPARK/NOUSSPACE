# Black Hole Looks Like Code

Saved reference: a black hole whose structure resembles code.

![[blackhole-code.png]]

## Concept

The event horizon / accretion structure reads like lines of code — a visual metaphor for how code bends and consumes, how logic forms a gravitational center, and how the Nous Space universe is built from text.

## Why it matters for Nous Space

- Reinforces the **code-driven** aesthetic (zozuar shaders, Morflax, Tortoise).
- A striking hero/brand image: a black hole made of code.
- Ties to the cosmic theme (nature ≈ body ≈ universe) and the mind-as-microcosm idea.
