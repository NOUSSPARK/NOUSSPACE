# Nous Space — Knowledge Base

This folder is an [Obsidian](https://obsidian.md) vault. Open it in Obsidian via **Open folder as vault**.

## Structure

- `References/` — articles, docs, links we collect while building.
- `Tools/` — tools, libraries, services, and how we use them.
- `Ideas/` — feature ideas, experiments, brainstorming.
- `Notes/` — meeting notes, decisions, retrospectives.

## Conventions

- Use `[[wikilinks]]` to connect notes.
- Tag notes with `#reference`, `#tool`, `#idea`, `#decision`.
- Keep one idea per note; prefer many small notes over one big dump.
